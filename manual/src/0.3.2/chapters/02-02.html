Chapitre 2

Obtenir, installer et désinstaller

Pour cette build, vous compilez SUBDESTRUCKT sur votre Mac : aucun binaire n'est distribué. Le script fourni fait tout, gratuitement.

Licence JUCE : votre choix

SUBDESTRUCKT utilise JUCE, disponible sous deux licences : AGPLv3, ou la licence JUCE 9 (niveau gratuit Starter sous un plafond de revenus). Le script ne choisit rien à votre place : il vous demande d'indiquer la licence que vous avez retenue (étude : docs/V1-ARCH-G4.1-LICENCE.md).

Compiler sur votre Mac

  1. Installez les outils gratuits : xcode-select --install, puis brew install cmake ninja.
  2. Récupérez les sources au commit indiqué par la direction technique.
  3. Validez ou retirez vos modifications locales : le script refuse un dépôt modifié (compilation non reproductible).
  4. Lancez tools/local-build/build_local_macos.sh --juce-licence=<votre choix> (option --commit=<sha> pour un autre commit).
  5. Le script exporte les sources exactes du commit, vérifie JUCE et pluginval (SHA), compile, exécute les tests, contrôle l'identité du plugin, lance pluginval en rigueur 10 et assemble la livraison complète dans local-build/delivery-…. Il s'arrête au premier échec et ne produit alors aucune livraison. Le rapport (mesures de performance de votre Mac comprises) est dans local-build/out-….
  6. Il n'installe rien : ouvrez vous-même SUBDESTRUCKT_Installer.pkg (ci-dessous). Il signale une copie de SUBDESTRUCKT présente à la fois dans votre dossier VST3 utilisateur et dans le dossier système, sans y toucher.

Contenu de l'archive

  • SUBDESTRUCKT_Installer.pkg et SUBDESTRUCKT_Uninstaller.pkg
  • README_FR.txt, CHANGELOG.txt, SHA256SUMS.txt

Installer

  1. Fermez toute DAW qui utilise SUBDESTRUCKT.
  2. Vérifiez l'empreinte (chapitre 17, test R-01).
  3. Ouvrez l'Installer. Le paquet n'est pas signé : macOS le signale. Ouvrez Réglages Système › Confidentialité et sécurité, puis « Ouvrir quand même » pour ce paquet uniquement. Ne désactivez jamais Gatekeeper globalement.
  4. Saisissez votre mot de passe : le plugin est installé dans /Library/Audio/Plug-Ins/VST3/SUBDESTRUCKT.vst3.
  5. Relancez la DAW et l'analyse des plugins si nécessaire.

Mettre à jour depuis 0.2.0

Installez par-dessus : la version précédente est détectée, sauvegardée pendant l'opération et restaurée en cas d'échec. Une ancienne copie installée par le script 0.3.0 (option --install, supprimée en 0.3.1) se trouve dans ~/Library/Audio/Plug-Ins/VST3 : retirez-la avant la recette pour éviter un doublon.

Désinstaller

Ouvrez l'Uninstaller. Il ne retire que le bundle SUBDESTRUCKT identifié et son reçu. Vos presets (~/Library/Application Support/Labtechno/SUBDESTRUCKT/Presets), vos banques (…/Wavetables) et votre MIDI Learn sont conservés. Ancienne installation par le script 0.3.0 (--install) : supprimez ~/Library/Audio/Plug-Ins/VST3/SUBDESTRUCKT.vst3.
