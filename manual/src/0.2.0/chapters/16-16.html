Exemples audio

Des sons produits par le moteur DSP réel de cette build, avec tous leurs réglages.

Comment ces sons ont été produits
  • Moteur : le cœur DSP non modifié (source/) au commit indiqué dans audio/examples.json, par l'outil tools/manual-audio/render_examples_g4.cpp.
  • Format : WAV 24 bits, mono (stéréo mixée), 48 kHz, Quality Normal.
  • Niveau : partie tenue normalisée à −20 dBFS RMS, crête limitée à −1 dBFS.
  • Plateforme de rendu : Windows (MSVC) à partir des mêmes sources que le plugin macOS ; l'identité échantillon par échantillon avec le plugin macOS n'est pas vérifiée.
