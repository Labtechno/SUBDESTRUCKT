Chapitre 2

Obtenir, installer et désinstaller

Pour cette build, vous compilez SUBDESTRUCKT sur votre Mac : aucun binaire n'est distribué. Le script fourni fait tout, gratuitement.

Licence JUCE : votre choix

SUBDESTRUCKT utilise JUCE, disponible sous deux licences : AGPLv3, ou la licence JUCE 9 (niveau gratuit Starter sous un plafond de revenus). Le script ne choisit rien à votre place : il vous demande d'indiquer la licence que vous avez retenue (étude : docs/V1-ARCH-G4.1-LICENCE.md).

Compiler sur votre Mac

  1. Installez les outils gratuits : xcode-select --install, puis brew install cmake ninja.
  2. Récupérez les sources au commit indiqué par la direction technique.
  3. Lancez tools/local-build/build_local_macos.sh --juce-licence=<votre choix> --install --pluginval.
  4. Le script vérifie JUCE (SHA), compile, exécute les tests, signe le plugin localement et l'installe dans ~/Library/Audio/Plug-Ins/VST3. Le rapport est dans local-build/out (mesures de performance de votre Mac comprises).

Avec --packages, le script produit aussi, en local, les paquets Installer/Uninstaller et l'archive décrits ci-dessous.

Contenu de l'archive

  • SUBDESTRUCKT_Installer.pkg et SUBDESTRUCKT_Uninstaller.pkg
  • README_FR.txt, CHANGELOG.txt, SHA256SUMS.txt

Installer

  1. Fermez toute DAW qui utilise SUBDESTRUCKT.
  2. Vérifiez l'empreinte (chapitre 17, test R-01).
  3. Ouvrez l'Installer. Le paquet n'est pas signé : macOS le signale. Ouvrez Réglages Système › Confidentialité et sécurité, puis « Ouvrir quand même » pour ce paquet uniquement. Ne désactivez jamais Gatekeeper globalement.
  4. Saisissez votre mot de passe : le plugin est installé dans /Library/Audio/Plug-Ins/VST3/SUBDESTRUCKT.vst3.
  5. Relancez la DAW et l'analyse des plugins si nécessaire.

Mettre à jour depuis 0.2.0

Installez par-dessus : la version précédente est détectée, sauvegardée pendant l'opération et restaurée en cas d'échec. Avec --install, le bundle de votre dossier utilisateur est simplement remplacé.

Désinstaller

Ouvrez l'Uninstaller. Il ne retire que le bundle SUBDESTRUCKT identifié et son reçu. Vos presets (~/Library/Application Support/Labtechno/SUBDESTRUCKT/Presets), vos banques (…/Wavetables) et votre MIDI Learn sont conservés. Installation par le script (--install) : supprimez ~/Library/Audio/Plug-Ins/VST3/SUBDESTRUCKT.vst3.
