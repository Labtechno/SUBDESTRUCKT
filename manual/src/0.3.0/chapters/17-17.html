Recette et dépannage

La recette physique vérifie sur un vrai Mac ce que les tests automatisés ne peuvent pas vérifier.

Dépannage

  • Le plugin n'apparaît pas : relancez l'analyse des plugins VST3 de la DAW ; vérifiez la présence de SUBDESTRUCKT.vst3 dans /Library/Audio/Plug-Ins/VST3 (paquet) ou ~/Library/Audio/Plug-Ins/VST3 (script).
  • La compilation échoue : lisez local-build/out/build.log ; vérifiez Xcode Command Line Tools, cmake et ninja.
  • « ELP » s'affiche : des gains cumulés dépassent +24 dBFS ; baissez les gains de sortie des processeurs ou Output Gain.
  • Silence : vérifiez WT Level et les niveaux des opérateurs, Output Gain, le Cross Audio (Crossfade à une extrémité), puis PANIC.
  • Son qui persiste : un emplacement armé (Autonomous Armed) ou le Drone ; décochez-les ou PANIC.
  • Un preset ne gèle plus comme avant : les armements d'un preset sont volontairement ignorés ; réarmez l'emplacement.
  • Clic au changement d'algorithme : les changements structurels sont amortis mais aucune absence de clic n'est garantie.
  • Projet 0.3.0 ouvert dans une version antérieure : l'état est refusé (format plus récent) ; gardez une copie avant tout retour arrière.
