# SUBDESTRUCKT — Spike S0.1 — Validation finale du retard causal
Date : 2026-11-24. Statut : **MISSION R&D À EXÉCUTER**.

## 1. Contexte
Le spike S0 a validé la stratégie **B** :
- seules les arêtes nécessaires pour casser un cycle sont retardées;
- les routes feed-forward restent Immediate;
- la classification causale devient **sticky et persistante**.

S0.1 ne doit donc PAS réouvrir A vs B.

La seule question principale restante est :
**B-T1 ou B-T2 ?**

Avec :
- **T1** = 1 sample hôte;
- **T2** = durée physique fixe de 1/48000 s = 20.833333 µs.

## 2. Décisions déjà figées
Ces points ne sont pas à réarbitrer :
1. stratégie B;
2. CausalClass sticky;
3. StableRouteID + CausalClass persistés;
4. une route survivante ne change jamais automatiquement de classe;
5. ajouter une route : Immediate si possible sans cycle, sinon Delayed;
6. supprimer une route : aucune reclassification automatique des survivantes;
7. si T2 est finalement retenu, K≥2 est obligatoire à 44.1 kHz pour le réseau récursif;
8. si T2 est retenu, il s'applique à toutes les arêtes causalement retardées FM/CROSS et seulement elles.

## 3. Objectif
Déterminer si T2 apporte un bénéfice technique, sonore ou de cohérence suffisant pour justifier :
- le délai fractionnaire;
- le coût éventuel supplémentaire;
- le K≥2 obligatoire à 44.1 kHz;
- la complexité accrue par rapport à T1.

Résultat attendu :
- **GO-B-T1**
- **GO-B-T2**
- ou **NO-GO** si le harness doit encore évoluer.

## 4. Extension obligatoire du harness

### 4.1 Modes de modulation
Ajouter et tester :
- PM — référence S0;
- Linear FM;
- Through-Zero FM;
- Exponential FM.

Respecter les bornes candidates existantes du baseline.
Ne pas introduire de pitch compensation non spécifiée.

### 4.2 Wavetable minimale réelle
Remplacer le pseudo-WT sinus par un petit moteur de table réel, minimal mais déterministe.

Inclure au minimum :
- sine;
- triangle band-limited ou table préconstruite;
- saw band-limited ou table préconstruite;
- une forme plus riche/asymétrique.

Pas de Z, pas d'éditeur de banques, pas de Character complet.

### 4.3 Oversampling / resampling réel
Le chemin temps réel du harness doit inclure le vrai mécanisme d'oversampling/resampling testé, pas uniquement une décimation offline.

Comparer :
- 1×;
- 2×;
- 4×.

À 44.1 kHz :
- T1 peut rester à 1×;
- T2 doit utiliser au moins 2× dès qu'une arête Delayed existe.

Mesurer explicitement le coût de cette asymétrie.

## 5. Classification causale sticky
Implémenter le contrat validé.

Pour chaque route :
- StableRouteID;
- source;
- destination;
- CausalClass = Immediate ou Delayed;
- état actif;
- profondeur.

Règles transactionnelles :
1. route survivante → classe inchangée;
2. nouvelle route → Immediate si le sous-graphe Immediate reste acyclique;
3. sinon → Delayed;
4. suppression → aucun reclassement automatique;
5. source/destination modifiée = suppression + création;
6. état sauvegardé/rechargé → même classification;
7. validation à la lecture : sous-graphe Immediate obligatoirement acyclique.

Tester explicitement qu'une topologie visuellement identique rechargée depuis son state reproduit le même rendu.

## 6. Transitions topologiques

Durées :
- 64;

- 1024 samples hôte.

Courbes :

Scénarios :

## 8. Mesures numériques

### Déterminisme
- même état → même rendu;
- sauvegarde/rechargement sticky → même rendu;
- block-size invariance;
- transaction aux mêmes sample offsets.

### Stabilité
Particulièrement importante pour Linear FM / TZFM / Exponential FM :
- NaN/Inf;
- runaway;
- DC;
- pitch/frequency bounds;
- state explosion;
- récupération après Panic/reset si applicable.

### Spectral
Comparer B-T1 vs B-T2 :
- PSD/Welch;
- distances spectrales;
- aliasing;
- énergie hors bande avant resampling;
- variation entre sample rates.

### Temporel
- phase;
- retard effectif;
- transitions;
- click metrics;
- convergence/divergence des régimes récursifs.

## 11. Délai fractionnaire T2
Le Lagrange cubique de S0 est un candidat, pas une décision produit.

Comparer si pertinent au moins :
- Lagrange cubique;
- une alternative fractionnaire à magnitude mieux contrôlée ou coût plus faible si raisonnablement implémentable.

Évaluer :
- magnitude;
- phase;
- retard;
- coût;
- stabilité en feedback.

Ne pas complexifier inutilement : l'objectif est de vérifier que T2 ne paie pas sa cohérence temporelle par une coloration problématique.

## 12. Critères de décision

### GO-B-T2 si
- stabilité confirmée dans tous les modes;
- comportement entre sample rates plus cohérent ou avantage perceptif crédible;
- coût M1 acceptable;
- 44.1 kHz K≥2 soutenable;
- délai fractionnaire sans défaut musical problématique;
- transitions propres;
- complexité supplémentaire justifiée.

### GO-B-T1 si
- T2 n'apporte pas de gain clairement utile;
- ou T2 coûte sensiblement plus cher;
- ou le délai fractionnaire colore trop;
- ou K≥2 à 44.1 kHz est disproportionné;
- ou T1 donne un caractère aussi bon/meilleur avec une implémentation nettement plus simple.

### NO-GO si
- les modes FM supplémentaires révèlent un problème structurel de causalité/stabilité qui invalide le harness actuel.
